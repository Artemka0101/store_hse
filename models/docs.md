# store_hse - витрины интернет-магазина по схеме "звезда"

## О проекте
Проект store_hse — это готовая аналитическая витрина данных для интернет-магазина, построенная на базе Greenplum с использованием dbt. Он превращает сырые OLTP-таблицы в удобные структурированные модели, пригодные для комфортной работы с огромными объёмами информации об интернет-магазине.

## Ключевые возможности

Аналитикам часто приходится вручную собирать данные из разрозненных таблиц, проверять их корректность и как-то сопоставлять между собой, что отнимает очень много времени и порождает ошибки. Большую часть этой работы store_hse может взять на себя. 

Он может осуществить:

- Автоматическую сборку из сырых данных
- Встроеную проверку качества данных
- Единую систему идентификации товаров, клиентов, категорий товаров и др.
- Оптимизацию под Greenplum для значительного ускорения запросов 

## Важные преимущества

- Трёхслойная архитектура данных: staging-слой очищает сырые данные, intermediate-слой реализует основную логику, marts-слой отдаёт готовые к использованию витрины.
- Схема "звезда": две факт-таблицы (fct_orders, fct_order_items) и три измерения (dim_customers, dim_products, dim_dates) - привычно и удобно для любой аналитики
- Автоматические тесты: более 10 generic-тестов на уникальность значений, непустоту, корректность связей и т.д., и ещё 5 singular-тестов на сверка сумм, проверка возвратов, поиск переплат и др.
- Оптимизация: колоночное хранение и правильное распределение по ключам для быстрого выполнения аналитических запросов

## Как начать работу?

Сборка всех моделей - выполнить в корне проекта dbt run

Запуск тестов - dbt test

Подтверждённая покупка — это заказ, для которого одновременно выполнены два условия:
- статус заказа равен paid (оплачен).
- есть хотя бы одна успешная платёжная операция (payment_status = 'success'), не являющаяся возвратом.

Тестовые заказы в витрину не попадают.
